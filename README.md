# 栖伴 Qiban · 陪伴 Agent 交互原型

一个简约、安静的跨设备陪伴产品原型。包含三个原创 SVG 桌宠：**糯米、星弥、曜**。

## 体验范围

- 三款桌宠切换、互动与形象介绍。
- 陪伴对话：使用本地规则演示，**没有接入真实 AI 模型**。
- 成长目标：添加目标、勾选步骤、专注计时与复盘。
- 记忆：新增、编辑、删除、分类、搜索。
- 设备：四端设备演示、摄像头请求 / 手机确认 / 结束共享的交互流程。
- 深浅色主题、手机布局预览、页面内可拖动桌宠。
- 浏览器本地持久化、导出、清除数据。

## 本地运行

无需安装依赖或构建：

```sh
python3 -m http.server 4173
```

打开 `http://localhost:4173`。也可使用任意静态文件服务器。

## 部署

`.github/workflows/pages.yml` 会在推送到 `main` 后将静态页面部署到 GitHub Pages。仓库需在 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。

## 文件

- `index.html`：应用框架。
- `style.css`：响应式布局与主题。
- `pets.js`：三款原创矢量桌宠。
- `app.js`：原型状态、交互和演示流程。

## 数据与权限

所有个人输入仅存储在当前浏览器的 `localStorage`，不会上传至服务器。不申请摄像头和麦克风权限，不建立真实跨设备连接。本次不记忆模式不保存该模式中新产生的对话。

初始目标、设备、记忆均为演示数据。公开部署不包含用户账号、API 密钥或真实个人资料。页面字体可从 Google Fonts 加载；不可用时使用系统字体。

这是一份体验原型，还不是可安装的 iOS、Android、Windows 或 macOS 原生应用。
